## 术语核对

- 对用户结果使用“恢复快照 / recovery snapshot”。
- “保护快照 / protection snapshot”只用于底层完整性、回收站状态和永久删除说明。
- 产品描述现在同时覆盖全文搜索、只读预览、ZIP 备份恢复、可撤销回收站、恢复快照、保留策略和 Origins & Branches。
- README 与 npm 包不再引用已删除的旧截图文件。

## 证据限制

截图能够验证视觉布局、文案、状态和主要入口；不可仅凭截图证明数据持久化、崩溃恢复、权限边界或跨版本兼容性。这些部分由 `npm test`、路由测试、恢复事务测试和浏览器交互测试覆盖。
